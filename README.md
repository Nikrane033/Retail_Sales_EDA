# Retail Sales Exploratory Data Analysis (EDA)

## Project Overview

This project performs exploratory data analysis (EDA) on a retail sales dataset using Python. It covers initial data inspection, data quality checks, cleaning and transformation, feature engineering, univariate and bivariate analysis, and outlier treatment.

The notebook creates visualizations to explore customer demographics, product categories, payment methods, order quantities, sales-related fields, and patterns across years.

## Dataset

- **Dataset filename used in the notebook:** `retail.csv`
- **Initial dataset size:** 3,060 rows and 17 columns
- **Columns include:** `OrderID`, `OrderDate`, `CustomerName`, `CustomerAge`, `Gender`, `CustomerCity`, `ProductCategory`, `ProductName`, `Quantity`, `UnitPrice`, `DiscountPercent`, `DeliveryDays`, `PaymentMethod`, `CustomerRating`, `ShippingCost`, `CouponCode`, and `ReturnReason`.
- The notebook loads the dataset from a local Windows file path. Update that path to the location of `retail.csv` on your computer before running the notebook elsewhere.

> The `retail.csv` dataset was referenced by the notebook but was not included with the uploaded notebook. Add it to the repository only if you have permission to share it.

## Project Workflow

### 1. Initial Data Inspection
- Checked the dataset dimensions, column names, data types, and descriptive statistics.
- Identified data-quality issues such as missing values, inconsistent gender labels, negative quantities/discounts/delivery days, and values outside expected ranges.

### 2. Data Cleaning
- Identified and removed 60 duplicate rows, reducing the dataset from 3,060 to 3,000 rows.
- Standardized inconsistent values in the `Gender` column.
- Converted negative values in `Quantity`, `DiscountPercent`, and `DeliveryDays` to absolute values.
- Capped `DiscountPercent` between 0 and 100.
- Replaced `CustomerAge` values below 16 or above 75 with missing values.
- Removed rows with missing `UnitPrice`.
- Filled missing values in selected columns:
  - `CustomerAge` with 34
  - `Gender` with `Male`
  - `CustomerCity` with `Lucknow`
  - `PaymentMethod` with `UPI`
  - `CustomerRating` and `ShippingCost` with 0
- Retained missing values in `CouponCode` and `ReturnReason`.

### 3. Date Transformation
- Converted `OrderDate` to datetime format.
- Extracted `Year`, `MonthName`, `DayName`, and `Quarter` for time-based exploration.

### 4. Feature Engineering
- Created a `Sales` column using the notebook's calculation:

  `Sales = Quantity * UnitPrice * (1 - DiscountPercent / 100) + ShippingCost`

- Created `Quantity_Status` to group orders into `Low Order`, `Medium Order`, `High Order`, and `Very High` categories.

### 5. Exploratory Data Analysis and Visualization
The notebook includes:

- **Count plots** to examine categorical variables and compare categories across years.
- **Histograms** to inspect distributions of numerical variables.
- **Pie chart** to visualize the distribution of customer ratings.
- **Pair plot** to explore relationships among variables.
- **Grouped count plots** to compare gender and product category, and payment method and year.

### 6. Outlier Treatment
- Applied the IQR method to numerical columns.
- Used lower and upper IQR boundaries to clip values.
- Created a box plot to inspect numerical columns after clipping.

### 7. Export
- Exported the processed dataset as `cleaned_sales.csv`.

2. Place `retail.csv` in the project folder (if you are permitted to share and include the dataset).
3. Open `Python_EDA_Project.ipynb` in Jupyter Notebook or JupyterLab.
4. Update the `pd.read_csv(...)` path in the notebook to a relative path such as:

   ```python
   df = pd.read_csv("retail.csv")
   ```

5. Install the required libraries:

   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

6. Run the notebook cells in order. The final cell saves the cleaned data as `cleaned_sales.csv`.
